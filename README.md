# AI 브리핑

Claude Code를 쓰는 개발자를 위한 주간 브리핑입니다. 화요일과 목요일에 자동으로 만들어 이 저장소에 올립니다.

**보기:** https://jina1003.github.io/ai-briefing/

| 요일 | 호 | 내용 |
|---|---|---|
| 화 | AI 트렌드 노트 | 이번 주 소식 3~4건 + 실무 가이드 1~2편(설치 → 실습 → 프롬프트 → 안 될 때) |
| 목 | 스킬 도감 | 에이전트 스킬 · 플러그인 5~7개. 순위는 낮아도 급상승한 것을 우선 |

## 어떻게 고르나

- **스킬 급상승:** skills.sh 주간 설치 수를 저장소 단위로 본다. 지난주가 직전 3주 평균보다 2.5배 이상이고 1,500건 이상 늘었으면 급상승으로 판정한다. 복제 저장소, 조작이 의심되는 저장소, 4주 안에 이미 소개한 저장소는 뺀다.
- **상위권 · 화제:** Best Skills 순위, GitHub 일간 트렌딩(지난 7일 중 오른 날 수), 별 7일 증가, Claude 공식 플러그인 마켓 신규 등록.
- **소식:** Anthropic · Claude 블로그 새 글, Claude Code 변경 이력, OpenAI · Google AI 블로그, Hacker News 상위, GeekNews, Simon Willison, Show HN.

## 검증

- 설치 명령은 출처 문서(공식 문서 · README · skills.sh)의 본문에 글자 그대로 있을 때만 싣는다. 없으면 그 항목은 뺀다.
- 이 검증은 문서에 그렇게 적혀 있는지 확인한 것이다. 실제로 설치해 본 것은 아니다.
- 수치는 출처에 있는 것만 쓴다. 공식 발표, 외부 측정, 의견을 구분해 표시한다.
