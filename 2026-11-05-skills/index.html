Elephant-Goldfish Model

무엇인가

AI 에이전트로 소프트웨어 설계를 쓰고 검토하는 구글의 오픈소스 스킬 묶음이에요. 프로젝트 맥락을 가진 Elephant가 명세를 쓰고, 이전 대화를 모르는 Goldfish가 초안을 읽어 숨은 가정을 드러내요. 아키텍처 결정과 구현 전 승인은 사람이 해요.

왜 지금

지난 7일 동안 별이 7,048개 늘어 누적 11,808개가 됐어요. 별 증가 상위 저장소 가운데 가장 새로운 프로젝트예요.

설치

claude plugin marketplace add google/elephant-goldfish-model

활용법

  1. claude plugin install egm@egm까지 실행해 플러그인을 설치해요.
  2. /egm:egm-brainstorm으로 아이디어를 정리해 콘셉트 요약을 만들어요.
  3. /egm:egm-draft로 설계 문서를 쓰고 /egm:egm-review <경로>로 다섯 단계 검토를 돌려요.

예시 프롬프트

/egm:egm-review docs/design/<기능이름>.md

주의. Goldfish 검토는 새 서브에이전트 맥락이 필요해요. 에이전트가 이를 만들 수 없으면 검토가 멈춰요. 구글이 공식 지원하는 제품은 아니에요(Apache 2.0).

Ponytail

무엇인가

에이전트가 "가장 게으른 시니어 개발자"처럼 생각하도록 가르치는 프롬프트 스킬이에요. 코드를 쓰기 전에 꼭 필요한지, 코드베이스에 이미 있는지, 표준 라이브러리 · 플랫폼 기능 · 기존 의존성으로 되는지, 한 줄로 되는지를 차례로 확인해요. 검증 · 보안 · 접근성은 줄이지 않는다고 적혀 있어요.

왜 지금

누적 별 184,543개인 대형 저장소인데 지난 7일에만 5,355개가 늘었어요.

설치

/plugin marketplace add DietrichGebert/ponytail

활용법

  1. /plugin install ponytail@ponytail까지 실행해 설치해요.
  2. /ponytail lite, full, ultra, off로 강도를 바꿔 가며 같은 요청의 결과를 비교해요.
  3. /ponytail-review로 지금 diff를, /ponytail-audit로 저장소 전체를 점검해요.

예시 프롬프트

/ponytail-audit 이 저장소에서 지워도 되는 코드와 표준 라이브러리로 바꿀 수 있는 코드를 심각도 순으로 알려줘.

주의. README는 GitHub의 DietrichGebert/ponytail 또는 npm의 @dietrichgebert/ponytail에서만 설치하라고 안내해요.

HyperFrames

무엇인가

HTML, CSS, 미디어, 애니메이션을 MP4로 바꾸는 HeyGen의 프레임워크예요. 에이전트가 이미 잘 쓰는 HTML로 영상을 짜고, 헤드리스 Chrome과 FFmpeg로 렌더링해요. 같은 입력이면 같은 프레임이 나와요.

왜 지금

지난 7일 동안 별이 4,214개 늘었고, 같은 기간에 v0.9.12부터 v0.9.14까지 릴리스가 세 번 나왔어요.

설치

claude plugin marketplace add heygen-com/hyperframes

활용법

  1. claude plugin install hyperframes@hyperframes까지 실행해 설치해요.
  2. npx hyperframes preview로 브라우저에서 바로 미리 봐요.
  3. npx hyperframes render로 MP4를 뽑아요.

예시 프롬프트

Using `/hyperframes`, create a 10-second product intro with a fade-in title, a background video, and subtle background music.

주의. Node.js 22 이상과 FFmpeg가 필요해요.

OpenMontage

무엇인가

AI 코딩 도구를 영상 제작 스튜디오로 바꾸는 오픈소스 시스템이에요. 파이프라인 12개와 도구 100개 이상을 묶어, 에이전트가 조사 · 대본 · 소재 생성 · 편집 · 합성을 차례로 해요. Archive.org, Pexels, NASA 같은 무료 소스의 실제 영상을 받아 편집해요.

왜 지금

지난 7일 중 4일 GitHub 일간 트렌딩에 올랐고, 한 주 동안 별이 3,743개 늘었어요.

설치

git clone https://github.com/calesthio/OpenMontage.git

활용법

  1. cd OpenMontage 후 make setup으로 환경을 갖춰요.
  2. Claude Code로 프로젝트를 열고 만들고 싶은 영상을 문장으로 말해요.
  3. 유튜브 · 릴스 링크를 붙여 넣어 콘셉트 2~3개부터 받아 봐요.

예시 프롬프트

Make a 60-second animated explainer about <주제>

주의. Python 3.10 이상, FFmpeg, Node.js 18 이상이 필요해요. API 키는 모두 선택이고, 기본 예산 상한은 제작 한 편당 $10, 건당 $0.50을 넘으면 확인을 받아요. 라이선스는 AGPLv3예요.

Beads

무엇인가

코딩 에이전트에게 오래가는 구조화된 기억을 주는 이슈 트래커예요. 마크다운 계획 대신 의존성 그래프로 할 일을 관리해, 긴 작업에서도 맥락을 잃지 않게 해요. Dolt 기반이라 버전 관리가 되고, 에이전트용 JSON 출력을 내요.

왜 지금

지난 7일 중 3일 GitHub 일간 트렌딩에 올랐고, 이번 기간에 v1.3.4가 나왔어요.

설치

curl -fsSL https://raw.githubusercontent.com/gastownhall/beads/main/scripts/install.sh | bash

활용법

  1. 프로젝트 폴더에서 bd init을 실행해요.
  2. bd setup claude로 Claude Code용 훅 · 설정을 깔아요.
  3. bd create "<할 일>" -p 0으로 작업을 만들고 bd ready로 막힌 것 없는 작업을 확인해요.

예시 프롬프트

`bd ready`로 지금 할 수 있는 작업을 보고, 하나를 `bd update <id> --claim`으로 맡은 뒤 끝나면 `bd close <id>`로 닫아줘.

주의. 구버전 바이너리는 새 버전이 마이그레이션한 데이터베이스를 열지 못해요. HTTP 모드에서는 일부 동작이 거부되거나 줄어들어요.

Worktrunk

무엇인가

AI 에이전트를 병렬로 돌리기 위한 git 워크트리 관리 CLI예요. 워크트리를 브랜치 이름으로 부르고 경로는 자동으로 정해요. 만들기, 옮기기, 병합, 정리를 명령 하나로 줄여요.

왜 지금

Claude 스킬 · 플러그인 저장소 GitHub 트렌딩에 올라 한 주 동안 별이 1,261개 늘었어요.

설치

brew install worktrunk && wt config shell install

활용법

  1. wt switch -c <브랜치>로 새 워크트리와 브랜치를 만들어요.
  2. wt switch -x claude -c <브랜치> -- '<작업 설명>'으로 그 워크트리에서 Claude를 바로 띄워요.
  3. wt list로 상태를 보고, 끝나면 wt merge로 합치고 정리해요.

예시 프롬프트

wt switch -x claude -c fix-login -- '<로그인 오류 재현하고 고치기>'

주의. 빌드 캐시 공유는 APFS, btrfs, XFS 파일 시스템에서만 돼요.
