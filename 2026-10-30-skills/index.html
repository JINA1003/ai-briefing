security-audit (Cloudflare)

무엇인가

코딩 에이전트를 보안 감사자로 바꾸는 스킬이다. 정찰, 취약점 탐색, 후보 검증, 구조화 출력, 기록 재검증, 보고의 6단계를 서로 격리된 에이전트가 나눠 맡는다. 발견 항목은 findings.json에 confirmed, needs_validation, rejected로 기록되고 스키마 검사를 거친다.

왜 지금

지난주 설치 16,762건으로 직전 3주 평균 6,319건의 2.7배다. 지난 7일 중 5일 GitHub 일간 트렌딩에 올랐고 7일 동안 별이 13,290개 늘었다. 화요일 호에서 다뤘고, 이번에는 결과물을 읽고 다시 돌리는 법에 초점을 둔다.

설치

npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit

활용법

  1. 감사할 저장소에서 Claude Code를 열고 security audit this codebase라고 요청한다.
  2. 결과 폴더(기본값 ~/security-audit-skill/<repo-name>/run-<N>)에서 REPORT.md와 NEEDS-VALIDATION.md를 먼저 읽는다.
  3. 한 번 더 돌린다. README에 따르면 한 번 실행으로 반복 실행 전체가 찾은 취약점의 절반쯤을 찾고, 다음 실행은 이전 원장과 발견을 이어 받아 빈틈을 노린다.

예시 프롬프트

find security vulnerabilities in ./<src 폴더>. 결과는 저장소 밖 기본 폴더에 저장하고, 끝나면 REPORT.md의 confirmed 항목만 한국어로 요약해 줘.

주의. 대상 코드를 실제로 실행하려면 외부 네트워크를 막고 쓰기를 제한한 OS 수준 샌드박스가 필요하다. 없으면 코드를 실행하지 않고 needs_validation으로 남긴다. 병렬 서브에이전트를 지원하는 모델과 검증 스크립트용 Node.js가 필요하다.

Claude SEO

무엇인가

Claude Code용 SEO 플러그인이다. 하위 스킬 26개와 전문 에이전트 19개로 기술 SEO, 콘텐츠 품질, 구조화 데이터, AI 검색 인용 가능성, llms.txt 같은 에이전트 준비도를 본다. README는 전체 감사에 10~15분이 걸리고 결과를 중요도 순 수정 목록으로 준다고 적는다.

왜 지금

지난 7일 중 4일 GitHub 일간 트렌딩에 올랐고, 한 주 동안 별이 4,110개 늘었다.

설치

/plugin marketplace add AgriciDaniel/claude-seo

활용법

  1. 이어서 /plugin install claude-seo@agricidaniel-claude-seo로 설치하고 /seo setup을 실행한다. 별도 Python 환경과 헤드리스 브라우저가 깔린다.
  2. /seo page <url>로 페이지 하나부터 본 뒤 /seo audit <url>로 전체 감사를 돌린다.
  3. /seo agentic과 /seo schema로 AI 에이전트 준비도와 구조화 데이터만 따로 점검한다.

예시 프롬프트

/seo audit https://<내 사이트 주소>

주의. 에이전트 5개는 Opus, 나머지는 Sonnet으로 돌아서 전체 감사는 단일 페이지 점검보다 요금제 사용량을 많이 쓴다. 분석한 페이지는 Claude로 전송된다. Python 3.11~3.14가 필요하고, Google 키가 없으면 Core Web Vitals는 실험실 추정치다.

Impeccable

무엇인가

에이전트에 polish, critique, audit, bolder 같은 이름 붙은 디자인 동작을 주는 스킬 묶음이다. LLM 없이 도는 규칙 62개짜리 검출기가 어디에나 쓴 Inter 글꼴, 보라·파랑 그라데이션, 카드 속 카드 같은 AI 디자인 습관을 잡는다. README는 이미 있는 화면에서 가장 잘 듣는다고 적는다.

왜 지금

한 주 동안 별이 9,713개 늘어 GitHub 트렌딩에 올랐다. 7일 별 증가 10,336개로 별 상위 저장소 중 세 번째다.

설치

npx impeccable install

활용법

  1. 도구를 다시 불러온 뒤 /impeccable init으로 PRODUCT.md를 만든다.
  2. /impeccable critique <화면 이름>으로 점수와 우선순위가 붙은 UX 검토를 받는다. 페이지 전체보다 좁은 대상이 잘 듣는다.
  3. 터미널에서 npx impeccable detect src/로 검출기를 돌린다. 종료 코드 2면 문제를 찾은 것이다.

예시 프롬프트

/impeccable polish <설정 화면 경로>

주의. Claude Code에서 훅은 모델 명령을 거부해도 실행되므로 첫 편집 때 엔진을 내려받을 수 있다. 무인 실행 전에는 훅을 검토한다. 디자인 방향은 항상 impeccable.style에서 받아 오며, 텔레메트리는 npx impeccable telemetry off로 끈다. live 모드는 로컬 체크아웃에서만 쓴다.

Taste Skill

무엇인가

흔한 랜딩 페이지 대신 고객 맞춤 화면을 만들게 하는 스킬 design-taste-frontend 하나를 담는다. 디자인 방향 20개 중 3개를 제안받아 고르고, 공개 저작물 이미지로 페이지를 만든 뒤 실제 브라우저 세 폭에서 검사한다. v2.1부터 대시보드와 설정 화면용 경로도 따로 있다.

왜 지금

한 주 동안 별이 4,359개 늘어 GitHub 트렌딩에 올랐다. 7일 별 증가는 4,427개다.

설치

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

활용법

  1. Node 22 이상과 Chrome, Edge, Chromium 중 하나가 깔려 있는지 확인한다.
  2. 고객과 제품의 고유한 점을 담은 짧은 디자인 브리프를 준다.
  3. 스킬이 제안한 방향 3개 중 하나를 고르고, 스크린샷 자체 검토가 최대 3회 도는 것을 지켜본다.

예시 프롬프트

<업종>의 <회사 이름> 소개 페이지를 만들어 줘. 고유한 점: <재료·지역·역사>. 디자인 방향 후보 3개를 먼저 보여 줘.

주의. 한 번 빌드에 30~45분과 수십만 토큰이 든다. 이미지 검색에 인터넷이 필요하다. 쓰인 이미지는 CC 계열이라 페이지의 출처 표기를 지워선 안 된다.

Caveman

무엇인가

에이전트의 답을 짧게 만들고 읽는 입력을 압축해 토큰을 줄이는 스킬과 프록시다. 코드, 명령, 경로, 오류 메시지는 그대로 둔다. 보안 경고와 되돌릴 수 없는 작업 앞에서는 다시 완전한 문장으로 말한다.

왜 지금

지난 7일 중 4일 GitHub 일간 트렌딩에 올랐다.

설치

npx skills add JuliusBrussee/caveman -g

활용법

  1. 프록시 없이 스킬만 깔고 /caveman으로 켠다.
  2. 평소 작업 하나를 켠 상태와 끈 상태(/caveman off)로 해 보고 답 길이를 비교한다.
  3. 더 줄이고 싶으면 /ultracave를 써 본다.

예시 프롬프트

/caveman 이 저장소의 테스트 실패 원인을 찾아 줘.

주의. README 자체 측정으로 /caveman은 "간결하게 답하라"는 지시보다 중앙값 기준 약 3%만 더 줄인다. 규칙이 입력 토큰을 약 1,160개 더한다. 전체 CLI는 기본으로 사용 텔레메트리를 보내고, Auto 기능은 최근 요청과 첨부 파일을 Caveman Cloud로 보낸다.

Archify

무엇인가

시스템을 설명하거나 저장소를 읽게 하면 에이전트가 타입 있는 JSON 소스를 쓰고 검증해 대화형 HTML 도표로 만든다. 아키텍처, 시퀀스, 데이터 흐름, ERD 등 10가지 도표를 지원한다. 결과는 HTML 파일 하나라 Archify 없이도 브라우저에서 열린다.

왜 지금

별 91,435개의 큰 저장소인데 7일 동안 별이 3,829개 더 늘었다.

설치

npx skills add tt-a1i/archify -g

활용법

  1. Use Archify to draw: Browser -> API -> Redis cache -> PostgreSQL fallback처럼 한 줄로 그려 본다.
  2. 작업 중인 저장소를 열고 런타임 아키텍처 도표를 요청한다.
  3. "Redis 추가", "롤백 경로 강조"처럼 대화로 고치고, 뷰어에서 E로 PNG를 내보낸다.

예시 프롬프트

Use Archify to analyze this repository and produce a runtime architecture diagram. <강조할 경로>를 표시해 줘.

주의. 하루 한 번쯤 고정 서버에 업데이트 확인을 보낸다. ARCHIFY_UPDATE_CHECK_DISABLED=1로 끈다. 경로 추적은 도표에 그린 관계만 따라가며 영향이나 위험을 추론하지 않는다.
